## 12. README.md Documentation

Create a complete `README.md` file in the root directory of the project.

The README must explain:

1. **Project overview** — the purpose of KUSASA-ELIHLE Essential Candles and what the application does.
2. **Features** — the online shop, candle recommendation assistant, gift builder, shopping cart, customer assistant and any implemented AI productivity tools.
3. **Tools used** — the actual frameworks, libraries, database, AI services and development tools used in the project.
4. **Setup instructions** — prerequisites, how to clone or download the project, install dependencies, configure environment variables, run the application locally and build for production.

Include example commands, explain required configuration, and provide security guidance for API keys and customer information.

Ensure the README accurately describes the features actually implemented. Clearly identify demo features and integrations that still require configuration. Do not list technologies as used unless they are present in the project.
